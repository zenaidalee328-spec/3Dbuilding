# Claude setup for this project
Copy these into your Claude folder on a new PC:
- `agents/*.md` -> `%USERPROFILE%\.claude\agents\` (shorts-writer, shorts-director, shorts-creative-reviewer, shorts-tech-reviewer)
- `skills/shorts-studio`, `skills/videohub` -> `%USERPROFILE%\.claude\skills\`
Then say "nayi short banao" / "use the shorts studio". The pipeline is in skills/shorts-studio/SKILL.md.
The reviewers also need the reference sheets in `reference/` (kept only on the PC: the reference videos are not ours).
