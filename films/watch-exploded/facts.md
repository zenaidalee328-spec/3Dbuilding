# Inside a watch: facts to check before posting
- A mechanical watch runs on a wound mainspring, no battery; with servicing they run for decades.
- Gear train -> escape wheel -> pallet fork -> balance wheel (the escapement releases one tooth at a time).
- "Four times every second": true for 28,800 vph movements (4 Hz, 8 beats/s); many older watches run at 18,000-21,600 vph.
- Pivots run in synthetic rubies ("jewels") to cut friction and wear.
- "Over a hundred parts": typical movements have ~100-200+ parts.
- The movement in the film is a simplified, stylised layout built in code (not a real calibre).
